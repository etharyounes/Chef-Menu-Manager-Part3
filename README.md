# Chef's Menu Manager - Final Portfolio of Evidence (PoE)

##  Project Overview
**Chef's Menu Manager** is a cross-platform mobile application developed using **React Native** and **Expo**. Designed specifically for local restaurant owners and kitchen staff, this application transitions traditional paper-based menu keeping into an efficient, digital, and real-time management system. This repository represents the final completed submission adhering strictly to the module requirements and academic rubrics.

---

##  Key Implemented Features

1. **Complete Menu Management (CRUD Operations):**
   - **Create:** Validated input forms allowing the chef to add new dishes with a Name, Description, Course category, and Price.
   - **Read:** A clean, responsive list view displaying all registered menu items instantly.
   - **Update:** Pre-populated edit forms enabling seamless modification of existing dish details.
   - **Delete:** Immediate removal of outdated items with real-time UI state synchronization.

2. **Advanced Search and Filtering:**
   - **Real-Time Search Bar:** Instantly filters menu items by name dynamically as the user types.
   - **Course Filter Chips:** Interactive category selectors (`All`, `Starter`, `Main Course`, `Dessert`) for rapid navigation.
   - **Reset Functionality:** Quick clearing of active searches or filters to view the complete menu inventory.

3. **Menu Statistics Dashboard:**
   - Automatically calculates and displays the **total number of active items**.
   - Computes the **average pricing** across all registered dishes in South African Rand (R).
   - Provides individual category breakdown counts for Starters, Main Courses, and Desserts.
